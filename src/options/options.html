Bangladesh Railway QuickBook

Fill this in the night before. At ~07:50 you log in yourself, press ARM, and the extension does the rest until a CAPTCHA or the payment step, where it stops and hands the page back to you.

Journey

Station names must match what the site accepts. If its field requires choosing from a dropdown, type the name exactly as the site spells it.

Train priority

Partial names work — "Dhumketu" matches "DHUMKETU EXPRESS (770)". A train number on its own works too.

Class priority

Only classes the site actually offers are selected. A class card is treated as bookable only when the site renders its BOOK NOW button.

Seats

Never set above what your account is allowed to buy. The extension does not attempt to exceed the site's own limit and stops with the real error if the site refuses.

Timing

The clock schedules; the site decides. Firing early is not free, so leave the offset at 0 until a dry run tells you otherwise.

The SEARCH TRAINS button is enabled at all times, so a search sent before the date is released returns "No train found for selected dates or cities" rather than failing. The retries above re-submit the same search while that message is showing — about ten searches over four seconds by default. That is a handful of ordinary searches, not a refresh loop; raising it a lot would be.

Passengers

Stored locally with chrome.storage.local. Passwords, card numbers, CVV, OTP codes and CAPTCHA tokens are never stored — there are no fields for them.

What this extension will not do

  • Solve, read, forward or bypass a CAPTCHA, OTP or any security check
  • Store or enter payment credentials, or automate payment authentication
  • Exceed the ticket limit your account is allowed
  • Refresh in a loop, fire concurrent requests, or touch any private endpoint
